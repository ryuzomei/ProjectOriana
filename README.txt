ORIANA'S REDESIGNED ITE 1 PORTFOLIO
====================================

This is a redesigned version with a distinct editorial style: warm paper-like backgrounds, forest-green accents, terracotta details, serif display typography, thin borders, and an asymmetrical photo layout.

FILES
- index.html      Home page
- about.html      About Me page
- skills.html     Skills page
- projects.html   Project cards with replaceable links
- contact.html    Contact information and demo email form
- style.css       Shared design and responsive layout
- script.js       Theme toggle, mobile navigation, welcome alert, read more, back-to-top, contact form
- images/         Placeholder profile and project images

OPEN THE WEBSITE
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Keep all five HTML files, style.css, script.js, and the images folder together.

REPLACE YOUR PROFILE PHOTO
1. Put your photo inside the images folder, for example: my-photo.jpg
2. In index.html and about.html, find images/profile-placeholder.svg
3. Change it to your own filename, for example images/my-photo.jpg

REPLACE PROJECT LINKS
Open projects.html and search for PASTE_YOUR_PROJECT_LINK_HERE.
Replace each placeholder with your real URL. Each project card has two link placeholders; replace both with the same URL so the image and View Project button open the same project.
Edit titles and descriptions to match your completed class activities. Only include activities you completed, as instructed by your teacher.

CONTACT FORM
The contact form opens the visitor's default email app using mailto. It does not send messages through a server.

BEFORE SUBMITTING
- Replace the sample project titles, descriptions, links, and images.
- Adjust skill percentages so they honestly reflect your skills.
- Test all five pages and navigation links.
- Deploy the website using the hosting instructions provided by your teacher.
